# The Unwritten Company

**Every adventure becomes a legend. Most legends are accidents.**

An original tactical fantasy roguelike for iPhone, in which a custom hero and three recruited companions fight through coherently assembled, choice-driven miniature campaigns.

## Current verified development stage: v0.07

The repository currently contains an **early playable tactical training study**, not a campaign: four *illustrative* party characters, deterministic grid movement, an action-point command rail, two stationary target effigies with Guard and HP, seeded d20-style hit/miss/critical damage rolls, and original artwork. No foe takes turns yet; there is no completed battle, campaign, character recruitment flow, or persistent save data. Combat and offline operation were tested in automated Chromium, **not on a physical iPhone**.

Current player approval gate: **v0.09 — Gate A (NOT reached or approved).** Continue only through the next planned v0.08 milestone; never begin v0.10 without explicit approval. See the verified release ledger rather than interpreting roadmap entries as shipped features.
