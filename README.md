# The Unwritten Company

**Every adventure becomes a legend. Most legends are accidents.**

An original tactical fantasy roguelike for iPhone, in which a custom hero and three recruited companions fight through coherently assembled, choice-driven miniature campaigns.

## Current verified development stage: v0.09 — Gate A unapproved

The game currently contains one genuinely finishable, deterministic tactical skirmish with four controllable illustrated adventurers, two attacking enemy types, per-member AP/MP, pathfinding, real HP/damage/Guard, enemy telegraphs and victory/defeat/replay. It is not yet a complete narrative campaign, recruitment system or persistent RPG.

**Fourth v0.09 art/controls pass:** Added original flat manuscript floor engravings (Inkfall seal, map fragment, wax and leaf crest), precise command-legal enemy targeting marks instead of misleading range-only highlighting, and actual smooth miniature travel along the engine-approved path. Small-screen End Turn wording and movement feedback were polished. All assets remain original, static and locally cached.
