# The Unwritten Company

**Every adventure becomes a legend. Most legends are accidents.**

An original tactical fantasy roguelike for iPhone, in which a custom hero and three recruited companions fight through coherently assembled, choice-driven miniature campaigns.

## Current verified development stage: v0.09 — Gate A awaiting player review

The repository contains a **complete replayable tactical skirmish**, not a finished campaign. Four illustrated adventurers battle two enemy types using deterministic hit/damage rolls, Guard, pathfinding, AP/MP, telegraphed enemy turns, real party HP and win/lose/replay flow. The early training-study interface remains available. No custom hero creation, actual recruitment, campaigns, persistent battle saves or progression have yet been implemented.

**Latest visual Gate A correction (third pass):** original hand-painted cross-tile river and ivy joins, inked filigree around the manuscript-table frame, individual geometric party insignia, visually distinct enemy attack-versus-approach symbols, and new hand-finished armor embroidery, shield/rune engraving, beard braids, foliage and spectral facets on **all six** existing miniature designs. The command rail now uses clearer enemy attack/approach punctuation and slightly larger high-contrast labels; press states are more tactile, without changing control geometry. Missed attacks no longer cause false target recoil, while critical hits trigger a distinct stronger stagger. Original artwork, pointer safeguards, and offline caches remain.
