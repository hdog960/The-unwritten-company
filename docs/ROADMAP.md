# THE UNWRITTEN COMPANY — ONE HUNDRED RELEASE ROADMAP

All versions are sequential *real deliverables*, not individual chat messages or estimates of time. A version is verified only with committed implementation/art, appropriate actual tests, verified GitHub Pages status or plainly disclosed deployment blocker, and an updated release ledger. Planned version numbers are not shipped software.

**Gates:** v0.09 A (art + controls), v0.39 B (first complete adventure), v0.79 C (replayability), v0.99 D (release candidate). Explicit player approval is mandatory. Gate fixes do not magically advance a version. Quality beats speed.

Design authority: DESIGN_BIBLE, UI_CONTROLS_AND_ART_DIRECTION and HANDHELD_CONTROLLER_LAYOUT. iPhone landscape with separate DOM rails, GitHub Pages and no paid infrastructure. Prefer an accurate small slice over inflated unfinished counts.
